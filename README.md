# AUXIOL496_CSAT

Firmware for [STM32L496 Auxilliary IO board](https://github.com/MatthiasGeorgImhof/Hardware_CSAT/tree/main/auxio_board) that provides power and desktop communication.

Dependencies:
- [Common_CSAT](https://github.com/MatthiasGeorgImhof/Common_CSAT) provides provides all functionality. It is included as a **git subtree**.
